# Movie-Recommender-Website
An intelligent web app that recommends movies based on content similarity!

# Overview
An intelligent and interactive **Movie Recommendation System** that suggests movies along with their **posters**, based on content similarity. Built using **Python**, **Streamlit**, and **machine learning**, the app offers a fast and user-friendly experience.

**Deployed Live via Streamlit Cloud**  
[Try the Movie Recommender Website](https://maryadajain-movie-recommender-website-app-h2dqpj.streamlit.app/)



## Features

- Recommends **top 5 similar movies** based on selected input
- 🖼Displays **movie posters** for a visually rich experience
- Fast performance using **precomputed similarity matrix**
- Uses **cosine similarity** for content-based filtering
- Built with **Streamlit** for a smooth web interface
- **Live deployment** on **Streamlit Community Cloud**



## How It Works

1. The user selects a movie from a dropdown menu.
2. The app retrieves similar movies using a cosine similarity matrix.
3. Top 5 recommendations are displayed with posters using the TMDB API.
4. The app runs in a browser using Streamlit.


## Tech Stack

- **Python**
- **Pandas**, **Scikit-learn**
- **Streamlit**
- **TMDB API** 
- **Pickle** for model serialization
