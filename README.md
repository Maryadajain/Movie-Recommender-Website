# Movie-Recommender-Website
An intelligent web app that recommends movies based on content similarity!

# Overview
An intelligent and interactive **Movie Recommendation System** that recommends movies along with their **posters** based on content similarity. Built with **Python**, **Streamlit**, and **machine learning**, this web app offers a simple and user-friendly experience. The app is live and deployed using **Render**.


## 📌 Features

- 🎥 Recommends top 5 similar movies based on your input
- 🖼️ Displays **movie posters** for a visually rich experience
- ⚡ Fast recommendations using a precomputed similarity matrix
- 🧠 Content-based filtering using cosine similarity
- 💻 Built with Streamlit for a sleek web UI
- ☁️ Deployed live on Render for public access



## 🧠 How It Works

1. User selects a movie from the dropdown.
2. The backend uses a precomputed similarity matrix to find similar titles.
3. The top 5 most similar movies are displayed **with posters** using The Movie Database (TMDB) API.
4. The app runs smoothly in a browser via Streamlit.
